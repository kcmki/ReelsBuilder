1 · Connection
Where do I get these?
  1. In Graph API Explorer pick your app, add the permissions instagram_basic, instagram_content_publish, pages_show_list, pages_read_engagement, then generate a user token.
  2. Extend it in the Access Token Debugger ("Extend Access Token"), which lasts about 60 days.
  3. Query me/accounts?fields=instagram_business_account to find the account ID.
Changing your Facebook password invalidates the token; this page will tell you when that happens.
